Docker EE to Kubernetes migration

80+ applications, $1.8M in license costs avoided

At TransUnion I led the migration of 80+ applications from Docker EE to Kubernetes ahead of a hard deadline, which avoided $1.8M in enterprise license costs. About 3 of us did it over about 18 months. I converted the Compose deployments to Helm charts and wrote a Python health-check library that backs the pod probes for about 80 deployments.

Hard deadline. We made it.

TransUnion, 2019 to 2026 · Kubernetes · Helm · Python

Three Jenkins instances to one Harness platform

408 pipelines, 1,000+ repositories, 23 teams

At TransUnion I consolidated three separately maintained Jenkins instances onto one Harness platform, covering 408 pipelines, 1,000+ repositories and 23 development teams. OpenTofu codifies each team's access on a least-privilege model. Build times stayed about the same, and the gain was one CI system to maintain where there had been three.

Not faster. Just one thing to fix when it breaks.

TransUnion, 2019 to 2026 · Harness · Jenkins · OpenTofu

Pipeline factories

Release build job: 11 to 14 minutes, now about 3.4

At TransUnion a team gets a new Harness pipeline by adding an entry to a Terraform file, without waiting on the platform team. At The Lobbi Corp I built a GitHub Actions factory of 19 reusable composite actions (shared build steps), each pinned to an exact version across 17 repositories. It cut the release build job from 11 to 14 minutes down to about 3.4.

Wagon Works AI

In production beta with external testers

Wagon Works is The Lobbi Corp's AI assistant for small teams, a desktop app that works inside their Microsoft 365. It finds the file, names the source and drafts the next step, and a person approves before anything sends. I co-led the three-person team that took it to a production beta, from v1.0.0 through v1.0.28, with Azure-hosted licensing, Stripe seat billing and Entra sign-in.

A crash loop that led to a release gate

A release now fails on any unsigned file

Wagon Works crash-looped on fresh Windows 11 machines because Smart App Control, a Windows 11 security feature, blocked unsigned DLLs. I diagnosed it from PostHog telemetry and made full-payload code signing a release gate, so a release now fails on any unsigned first-party file.

Homelab

One server, about 2 years, about 20 Plex users

I have run one Unraid server for about 2 years. Its Docker services include Plex for about 20 users and Nextcloud on MariaDB, published through Nginx Proxy Manager with Let's Encrypt certificates and Cloudflare dynamic DNS. An Ansible playbook, unraidAnsible, sets the server up, and harnessUnraid is a template for running Harness CI/CD delegates (the workers that run its jobs) on Unraid.

Plex uptime is a family matter.
