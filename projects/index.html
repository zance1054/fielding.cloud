Docker EE to Kubernetes migration

Run

80+ applications $1.8M in license costs avoided

Docker EE is an enterprise container platform. At TransUnion I led the move from Docker EE to Kubernetes ahead of a hard deadline. About 3 of us did it over about 18 months. I converted the Compose deployments to Helm charts and wrote a Python health-check library that backs the pod probes for about 80 deployments.

Three Jenkins instances to one Harness platform

Ship

408 pipelines, 1,000+ repositories, 23 teams

At TransUnion I consolidated three separately maintained Jenkins instances onto one Harness platform, a build and deployment tool. OpenTofu codifies each team's access on a least-privilege model. Build times stayed about the same, and the gain was one CI system to maintain where there had been three.

Wagon Works AI

Ship

In production beta with external testers

Wagon Works (external site) is The Lobbi Corp's AI assistant for small teams, a desktop app that works inside their Microsoft 365. It finds the file, names the source and drafts the next step, and a person approves before anything sends. I co-led the three-person team through v1.0.0 to v1.0.28, with Azure-hosted licensing, Stripe seat billing and Entra sign-in.

The Lobbi Corp, Aug 2025 to present Azure Stripe Microsoft 365

LLM features with guardrails

Agents

Nothing publishes until its checks pass

I designed and delivered two pre-release LLM features for Wagon Works through coding agents. Task ranking accepts only schema-valid JSON, and meeting recaps publish only after every citation is checked against the transcript. I also led a security review before release and set the rule that the assistant's write tools need the person's approval once a turn has read outside content.

A crash loop that led to a release gate

Ship

A release now fails on any unsigned first-party file

Wagon Works crash-looped on fresh Windows 11 machines because Smart App Control, a Windows 11 security feature, blocked unsigned DLLs. I diagnosed it from PostHog telemetry and made full-payload code signing a release gate.
